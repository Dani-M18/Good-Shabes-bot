# Shabbat Calendar Bot

Функции:
- /start — выбрать город
- /city — сменить город
- /shabbat — ближайший Шаббат
- /holidays — ближайшие события
- пятница 09:00 — автоматическая сводка Шаббата
- воскресенье 09:00 — 3 ближайших события

Город и часовой пояс: Open-Meteo Geocoding.
Календарь и времена: Hebcal.com.
